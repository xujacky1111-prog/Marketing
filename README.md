# Marketing Repository

这是一个用于管理营销资产、活动计划和增长实验的专业仓库。

## 核心功能

- **营销日历 (Marketing Calendar)**: 可视化管理所有营销活动和关键里程碑。
- **活动管理**: 跟踪不同渠道（社交媒体、邮件、SEO 等）的执行进度。
- **资源库**: 统一存放品牌素材和文案模板。

## 目录结构

- `/marketing`: 存放营销相关的工具和页面。
- `/assets`: 存放静态资源（图片、Logo 等）。
- `/docs`: 营销方案和流程文档。
